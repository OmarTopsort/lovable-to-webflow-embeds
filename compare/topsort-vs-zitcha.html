Common questions.

Does Zitcha run the auction?

Zitcha focuses on operations and workflow, with core ad decisioning typically sitting in an underlying serving platform. Topsort provides that decisioning natively, so auction, relevance and optimization are a single decision.

Does Topsort include planning and collaboration workflows?

Yes. Advertiser self-service, agency workspaces, approvals and reporting are part of the platform, alongside the auction and optimization layer.

Can Topsort work alongside our current operations tooling?

Yes. Topsort is API-first, so it can run underneath existing planning tools during a migration and then consolidate once it is proven on live traffic.
