REBUILD

and 4174, run the capture-*.mjs scripts, then the corresponding generate-*.mjs
scripts, export-seo.mjs and sync-embed-aliases.mjs. The captures, CMS snapshot,
scoped CSS rules and browser behavior live in scripts/embed-src/.

Other event source folders, old standalone dropdowns, and .bak.html snapshots
are outside this source sync. The current navbar replaces the old dropdowns.
