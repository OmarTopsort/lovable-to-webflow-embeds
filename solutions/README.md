# Solutions embeds for Webflow

Refreshed from the current `/source` on October 7, 2026.

Each file contains numbered PART blocks. Paste each complete PART into a separate Webflow HTML Embed in order. CSS and JavaScript parts are included; every block is below 49,000 characters. The complete file is a reference, not a single paste block. Older separate `-partN.html` files have been replaced by this format.

Use the shared navbar and footer and keep `global-head.html` in the site head. See [the installation notes](../installation.text) for new pages, CMS, logins, and SEO.

See [../page-map.json](../page-map.json) for all exact source routes and paste counts. Each solution, including Offsite, In-store and the migration hub/children, is installed at its own `/solutions/...` route. Do not redirect these delivered pages to product pages, blog posts or the sales form.
